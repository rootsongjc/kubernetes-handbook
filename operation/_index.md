Kubernetes 集群运维是确保集群稳定运行和高效服务的关键环节。本章围绕集群的全生命周期展开：用 kubeadm 创建、配置与升级集群，理解 Kubernetes 的版本发布节奏与升级策略，建立覆盖 etcd、持久卷与期望状态的备份与灾难恢复体系，并介绍在混合集群中运行 Windows 节点的要点。节点自动扩缩与资源管理相关内容见"调度与弹性"章。
